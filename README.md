# EUCARPIA 2025 Biometrics in Plant Breeding Conference & Satellite Workshop

This is a repository hosting public information for the **EUCARPIA 2025 Biometrics conference** that will take place in Edinburgh 17-19th September 2025. The conference website incorporating this information is in development.

**The last EUCARPIA Biometrics in Plant Breeding Conference (2022)**: https://eucarpiabiom22.sciencesconf.org

**Web site updates**
The web site is generated from the branch called 'website'. To update, push to the 'devel' branch, then render locally and preview your changes. If happy, open pull a request from 'devel' to 'website'.
